Output a cell writes to stdout or fd 1, directly, from a thread or through a child process, no longer reaches the protocol pipe the host reads, so it can't pass for a result; the model sees the same output as before, and on Linux the supervisor is also non-dumpable. Not closed yet: in Linux subprocess mode a cell can still forge a result through the host's own pipe end in /proc until events are signed (#251), and code in the kernel, a thread a cell leaves running included, can still change what the kernel itself reports (the self-report class, left to the planned RE11 to RE13). With `--docker`, rebuild the image (`docker build -t analyst-kernel -f docker/Dockerfile .`) to get this: an older image keeps the old behaviour, and nothing detects it.
