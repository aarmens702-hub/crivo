`scripts/export_skills.py` no longer exports an admitted skill whose `scripts/fix.py` or `scripts/test_fix.py` changed since admission: it is refused, with a line naming the skill and the file. The MANIFEST now carries each exported skill's `scripts_sha256` beside SKILL.md's `sha256`, and a `scripts_pinned` flag that is true only when those hashes match a pin recorded at admission; a skill whose scripts are not pinned (a row from before #237, or no ledger row under `--all`) still exports, with a note saying so.
