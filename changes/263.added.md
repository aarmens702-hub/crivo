The bench now scores column removal on datasets that plant an extra column (a duplicate column, a damaged header): of the column labels the dirty frame holds that the pristine one lacks, how many are gone from the cleaned frame's columns and named index levels, compared exactly, so renaming one or moving it into a named index is not removing it (moving it into an unnamed index is not caught yet); `bench.run --smoke` prints it on a third line, and a run that leaves the planted column in place is no longer counted as solved.
