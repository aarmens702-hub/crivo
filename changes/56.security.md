An http(s) URL read with a token in its query string (`?api_key=...`) no longer leaves that token in the copies of the frame's lineage stamp: `attrs["remote"]["uri"]` keeps only the URL's scheme, host, port and path, so the card's lineage, the clean report's source, the cleaned file's lineage, provenance and a skill's `born_from` no longer carry the query (the fetch itself still sends the URL as given). The URL as typed still appears in the code cell that read it, in the session transcript, and in fetch error messages (#112).
