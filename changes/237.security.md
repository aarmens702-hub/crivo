A library skill whose `scripts/fix.py` or `scripts/test_fix.py` changed after you admitted it no longer runs: crivo records a hash of both scripts at admission, and at load a skill that no longer matches is skipped with a notice naming the skill and the file, and how to re-admit it (`git checkout skills/<name>` to restore it, or delete `skills/<name>/` so a later verified fix proposes it again); a skill admitted before this change still runs, with a one-time notice per session that it is unpinned.
