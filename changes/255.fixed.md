Clean mode no longer reverts every fix that removes whole rows: dropping duplicate rows, the later copy of a near-duplicate pair, or the flagged total rows now verifies when each row left is unchanged outside the fix's target columns (in every column, for total rows), whether the index labels are kept or reset. Such a fix is still reverted when it also changes a cell outside its targets, sorts the rows and resets the index, drops a detail row in place of a total, or drops a row that is not a copy of one it kept; a total-row fix that also repairs the label column's padded header is reverted too, so repair the header in its own fix.
